# Index open degradation audit (VN30 index open 2018-2022)

Diagnostic only. Read-only on data/raw/ and results/; regime and Monday-share results are not recomputed. Script: `src/index_open_degradation_audit.py`.

Hypotheses (fixed by the brief): H1 the VN30 index open is degraded 2019 .. mid-2021 (e.g. reference prices for constituents with no ATO match anchor it near the prior close). H2 a date misalignment between the futures and index files in some 2019 quarters.

## Pre-registered rules (script header, fixed before the first run)

- H2: index shifted by positions in its own full calendar, then flagged opens masked; all five lags on the same nights. Off-zero peak supports H2 only if the peak is significant (Fisher z > 1.96), beats lag 0 by > 2 sqrt(2/(n-3)) in z, and close-to-close peaks at the same lag. CC at 0 with ON off zero rules out a whole-file shift.
- H1: primary = index ON with flagged index opens dropped vs PIT cap-weighted basket with all stock-days kept, one-day nights, common index/basket/futures dates. Support if pooled 2020Q1-2021Q2 SD(index)/SD(basket) < 0.50 while the pooled verified ratio is in [0.80, 1.25]. Reading map: basket normal & index collapsed -> index computation degraded (H1); both collapsed -> constituent-level anchoring (index not cleared, basket not a clean reference); neither -> H1 refuted.
- Version a (flagged stock-days dropped) removes zero returns and inflates basket SD: biased toward H1; reported, never counted as support (the open-filter audit's selection-on-outcome caveat: flagged names close 11.7 bp below unflagged names on the same date, t -5.77, so dropping them selects on the outcome).
